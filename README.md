# VOX Speak — Free Edition

Entrenador gratuito de inglés para móvil. Listening a ciegas, pronunciación mediante reconocimiento de voz y entrevistas de ventas/fintech.

Sitio en GitHub Pages: https://freddih13-arch.github.io/vox-speak-free/

Abre desde Chrome en Android y autoriza micrófono cuando se solicite. Requiere HTTPS para reconocimiento de voz; algunas funciones dependen del navegador y conexión. El progreso queda en localStorage del navegador.

No es una evaluación fonética médica/profesional ni tiene conversaciones de IA generativa. Los resultados de pronunciación son coincidencia aproximada de palabras reconocidas.
